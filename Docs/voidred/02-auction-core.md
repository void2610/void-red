# 02. 記憶オークション (コアルール)

プロトタイプで実装する本体。方式は**シールドビッド (封印入札)**。

## 参加者とロット

- 1 回のオークション参加者は **5 名** = 主人公ノア + 階層のライバルキャラ 2 名 + モブ参加者 2 名。
  - 0 階層 (チュートリアル) のみ、ライバル枠がアルヴ 1 名 + モブ 3 名。
- 1 回のオークションで出品されるロット (記憶) は **5 個**。1 個ずつ競り、5 ターン繰り返す。
- 全 5 階層 × 5 個 = 合計 25 個の記憶が存在する。
- 各ロットには必ず「目玉」が 1 つ含まれる。ただし**共鳴値の高低は出現順と相関させない** (ランダム配置)。
  - 理由: 順番が固定だと「最後に全部つぎ込むだけ」のゲームになる。テーマとの合致を自分で推測する遊びを残す。

## 1 ロットの進行

```
記憶テーマ表示
  └ ロット提示 (名称 / フレーバーテキスト / 感情属性)
      └ 対話フェーズ  … 対話コマンド (05 参照)。逆対話がここで発生
          └ 入札フェーズ … 感情属性ごとにホイールで枚数を決め、確定
              └ 一斉開示   … 全員の入札額を同時公開
                  ├ 単独最高額 → その場で落札 (頭上に WINNER 表示)
                  └ 最高額が同数 → 競合フェーズへ
                      └ 落札
```

これを 5 ロット分繰り返す。

## 入札

- 感情属性ごとにホイールを操作し、ボタンで枚数を決めて入札する (マウスホイール操作対応が望ましい)。
- **複数属性の組み合わせで入札できる**。入札額 = 属性を問わない合計枚数。
- **勝敗判定は属性を一切見ず、合計枚数のみで行う**。属性によるタイブレークは無し。
  - 属性の選び方は歪み (04) にのみ影響し、勝ち負けとは完全に独立している。
- 入札額が同数の場合、その全員が競合に入る (5 人同時競合もありうる)。
- 感情を賭ける行為は自分自身をすり減らす行為である、という設定上の意味を持つ。

## リソースの返却規則

| 状況 | 入札したリソース |
| --- | --- |
| 通常入札で落札 | 消費 (返らない) |
| 通常入札で落札できず | **全額返却** |
| 競合に入って落札 | 消費 |
| **競合に入って落札できず** | **返却されない** |

この二層構造がリスクテイクの設計上の要。

## 競合フェーズ

- 最高額が同数だった参加者のみが参加する。
- 制限時間内に **1 枚ずつクリックで追加入札**できる。誰も追加入札しなくなった時点で落札者確定。
- **追加入札に使う属性はプレイヤーが選ぶ**。通常入札と同じ感情属性ホイール UI で選択し、1 枚ずつ上乗せする。
- **パスの概念はない**。一度上乗せを止めても、制限時間内であればいつでも再度上乗せできる。
  最後の上乗せから一定時間 (旧実装では 10 秒) 誰も動かなければ確定する。
- **競合中の対話コマンドは使用できない** (改定で削除)。
- 競合に入った時点で、落札の可否にかかわらず入札済みリソースは返らない。

## リソースが尽きた参加者

- 所持リソースが 0 枚の参加者は、**そのロットの入札に参加しない** (卓から外れる)。
  - 0 枚入札として卓に残す扱いにはしない。全員 0 枚で競合が発生し、上乗せできず膠着するため。
- 補充は階層の開始時にしか行われないため、破産した時点でその階層では以後 1 つも落札できない。
  - すでに落札済みなら生存が確定し、無落札のまま破産すれば人格崩壊が確定する。

## 人格崩壊 (敗北)

- 定義: **そのオークションで 1 つも記憶を落札できなかった参加者**は人格崩壊を起こす。
  - リソースの破産そのものは崩壊条件ではない。
- 崩壊したキャラはその魂の時代へ送り返され、以降ロビーに登場しない。
  - そのキャラのストーリーはその周では回収不能になる。回収したい場合はセーブ / ロードで対応する。
- 逆に**生存したキャラは次の階層へ進む**。ストーリー上セリフが多少変化する。
  - ただし**次階層のオークションには参加しない**。オークションは小グループ制であり、
    前の階層で対戦したキャラとは二度と卓を囲まない、という設定にする。
- 最終ロットまで無落札のキャラは競合で必死に食い下がるため、終盤ほど競りが激化する。

## 主人公の敗北

- ノアが 1 つも落札できなかった場合は **ゲームオーバー**。
- **その階層の最初からやり直す** (階層をまたいで戻されることはない)。

## 情報公開の範囲

| 情報 | 公開 |
| --- | --- |
| 自分の所持リソース数 | 常時公開 |
| **他参加者の所持リソース数** | **常時公開** |
| 他参加者の入札額 | 一斉開示まで非公開 (観察コマンドで概数のみ推定可) |
| 所持リソースの属性内訳 | **非公開** (自分の分のみ見える) |

## 元ネタ / 価格方式

シールドビッドオークションは、互いの入札額を知らないまま同時に提出し最高額の者が落札する方式。
情報が隠されることで結託や不正を防ぎ、公平に適正価格を導く点に意義がある。

- 第一価格 (ファーストプライス): 自分の入札額をそのまま支払う。**現行仕様はこちら**。
- 第二価格 (ヴィックリー): 勝者は 2 番目に高い額を支払う。正直な入札が最適戦略になる。→ 採用可否は未定。
