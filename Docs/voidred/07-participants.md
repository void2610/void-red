# 07. 参加者 (入札 AI 仕様)

オークション AI として必要な情報のみを抜き出したもの。
キャラ設定・口調・過去は原典 `Docs/voidred.md` (Git 管理外) を参照。

> 【対話コマンドに対して】の各項は旧カードルール時代の記述をオークション用語に読み替えたもの。
> 「該当カード」= そのロット、「ベット数」= 入札枚数。**数値化は未確定**。

## 主人公ノア

- 司る感情属性: 葛藤 (どの感情状態にもなりうる。驚きと期待も併せ持つ)
- 象徴する罪: 嫉妬 (すべての罪を内包しうる、最も自己破壊的な罪)
- プレイヤー操作。名前・一人称を入力可能 (初期値: ノア / 私)

## 案内人アルヴ

- 0 階層 (チュートリアル) のみオークションに参加する。オークショニアも兼任。
- 司る感情属性: 葛藤 / 象徴する罪: 嫉妬
- 4 階層のモブに紛れている案 (未確定)。

## 1A 喜び — セリカ

| 項目 | 内容 |
| --- | --- |
| 罪 | 色欲 |
| 入札傾向 | 喜びの記憶を最高額とし、それ以外にも少量ずつ入札する |
| 対話耐性 | ほとんど効かない |
| 逆対話 | 仕掛けてくるが、セリカ自身の入札への影響は小さい |
| 挑発 | 変動なし |
| 共感 | 入札増加 |
| 説得 | 変動なし |
| 競合 | 基本的にそこまで追わない |

## 2A 信頼 — エリス

| 項目 | 内容 |
| --- | --- |
| 罪 | 暴食 |
| 入札傾向 | 対話しなければ全ロットに一律で同じ枚数を賭ける |
| 対話耐性 | そっくりそのまま反映される。最も操作しやすい |
| 逆対話 | 普通に仕掛けてくるが、わかりやすく従う |
| 挑発 | 入札増加 |
| 共感 | 変動なし |
| 説得 | 入札大幅減少 |
| 競合 | 競合する意思なし |

補足 (司る感情の善性・悪性):
- 信頼の善性 = 言い合わなくても通じ合える信頼、抱え込まず孤独や破滅に向かわない信頼
- 信頼の悪性 = いつもそうとは限らないのに思考停止している信頼、自分が逃れるために相手を盾にする独りよがりな信頼

## 2B 悲しみ — ミラ

| 項目 | 内容 |
| --- | --- |
| 罪 | 怠惰 |
| 入札傾向 | 広く浅く |
| 対話耐性 | 対話コマンドの裏をかいて動く |
| 逆対話 | 普通に仕掛けてくる |
| 挑発 | 該当ロットの入札を少し減らし、他ロットの入札を上昇 |
| 共感 | 入札大幅減少 |
| 説得 | 入札増加 |
| 競合 | 共感・挑発を行われたロットは追わない |

※ コマンドが行われなかったロットがある場合、共感・挑発による減少分だけそのロットの入札が増加する。

## 4A 怒り — レイナ

| 項目 | 内容 |
| --- | --- |
| 罪 | 憤怒 |
| 入札傾向 | 欲しい記憶 (怒り) に大量投入するパワープレイ |
| 対話耐性 | 反応がわかりやすい。ヴェイルの強化版 |
| 挑発 | 入札大幅増加 |

※ コマンドが行われなかったロットが 1〜2 個の場合、該当ロットの入札を取りやめ、他ロットへ振り分ける。

## 4B 驚き — モルガナ

| 項目 | 内容 |
| --- | --- |
| 罪 | 傲慢 |
| 入札傾向 | 全ロットに広く堅実に |
| 対話耐性 | 変動が大きく、裏をかいてくる |
| 逆対話 | 非常に高頻度で仕掛けてきてプレイヤーを翻弄する |
| 挑発 | 入札大幅減少、他ロットの入札上昇 |
| 共感 | 入札が完全ランダムに変動 |
| 説得 | 入札がランダムに増加。**驚き属性のロットでは大幅増加** |
| 競合 | 驚き属性は特に追い、躊躇せず確実に取りに行く |

※ コマンドが行われなかったロットが 3 個以上の場合、該当ロットの入札を取りやめ、他ロットへ振り分ける。

## モブ参加者

- 煉獄内の小さな罪を背負った魂から無作為に選出された凡人。
- 感情属性に対応して **8 種類**存在し、「(感情)する参加者」という名前を持つ。
- 各アーキタイプの基本の賭け方をベースにする。
- **対話コマンドの効果はそのまま反映される**ため入札の操作は容易い。
- 登場する種類は完全にランダム。
