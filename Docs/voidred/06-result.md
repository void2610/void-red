# 06. 洗礼 (リザルト / 人格構築)

オークション終了後のフェーズ。本編での名称は「洗礼」。
洗礼を受けた者だけが記憶を人格に統合し、次の階層へ進むことができる。

## 表示フロー

落札した記憶 1 個あたり、以下を繰り返す。

1. **落札内容の確認**
   - 記憶名 / 詳細説明 / 落札したターン
   - 自分が入札したリソース数と内訳
   - 他プレイヤーが入札したリソース数 (サブ要素)
2. **歪みの可視化**
   - その記憶を落札したことで生じた歪みを表示する (例: `悲しみ +1`)
   - 内訳が見やすい表現を検討する (グラフ等)

全ロット分を確認したあと、

3. **手元に残ったリソース数を表示**
4. **人格統合**: 落札した記憶の中から**任意の 1 つ**を選び、自分の人格に統合する
   - 統合しなかった記憶は**コレクション (図鑑) に入るだけ**で、人格には影響しない

## 統合の効果

- **歪みは統合した 1 個分だけが加算される**。落札しただけで統合しなかった記憶の歪みは反映しない。
- 主人公の**感情状態**は 8 感情のうち**いずれか 1 つ**を持つ状態として表現する。
- 統合した記憶の属性と歪みの度合いによって、感情状態が変化する。
- 感情状態は主人公の外見、対話コマンドのセリフ内容、エンディング内容に影響する。
- **感情状態の変化はプレイヤーに明示・表示しない**。

## 廃止された仕様

- マッチ度合いによる**報酬リソースは廃止**。報酬という概念自体をなくし、
  「歪み (マッチしていない感情リソース) の可視化」に置き換える。

## エンド分岐

- 各階層で統合した記憶の属性・共鳴値・歪みが分岐に関わる想定。
- **具体的な分岐条件は未定** ([10-open-questions.md](10-open-questions.md))。
- コンプリート率 (収集率) には依存させない。周回を強制しないための方針。
