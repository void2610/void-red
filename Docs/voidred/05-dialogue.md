# 05. 対話コマンド

入札確定前のフェーズでのみ使用できる。**競合フェーズでは使用できない** (改定で削除)。

## 基本ルール

- **各コマンドを、各キャラに対して 1 ロットにつき 1 回ずつ**使用できる。
  - したがって 1 ロットあたりの上限は **4 コマンド × 相手 4 人 = 最大 16 回**。
- 各コマンドには成功率がある。
- **失敗しても必ず何らかの情報が返る**。ただし返るのは**セリフのみ**で、数値ヒントは含まない。
  失敗時のキャラの反応がベット傾向のヒントになり、空振りターンをなくす。
- **NPC 同士は対話しない**。対話はプレイヤー起点のものと、それに対する逆対話だけが存在する。

| # | コマンド | 初期成功率 | 効果 |
| --- | --- | --- | --- |
| ① | 観察する | 85% | 対象が賭けようとしている**具体的な枚数のみ**を把握する (属性内訳は見えない)。**逆に対話を仕掛けられるリスクがある** |
| ② | 挑発する | 25% | 対象を煽り、入札額を増減させる。性格の見極めが必要 |
| ③ | 共感する | 25% | 共感を示し、入札額を上げる。相手によっては逆効果 |
| ④ | 説得する | 25% | 説得し、入札額を下げる。相手によっては逆効果 |

キャラごとの反応は [07-participants.md](07-participants.md) を参照。

## 逆対話 (キャラ側から仕掛けてくる)

- プレイヤーが「観察する」を行った際、一定確率でキャラ側が対話を仕掛けてくる。
- **各ロットにつき、各キャラ 1 回まで**。
- キャラの性格に沿った問いかけに対し、プレイヤーは二択で答える。
- 二択の返答次第でそのキャラの入札額が**大幅に変化**する。

## ボツ案: 感情状態による対話補正

> 1 階層以降、主人公の感情状態によって対話のセリフや成功率が変化する案。
> 効果は逆対話の二択の結果にも影響する。**現状ボツ**だが、記録として残す。

| 感情状態 | 効果 |
| --- | --- |
| 信頼 | 対話を仕掛けられる確率 −25% |
| 喜び | 「共感する」成功率 +25% / 効果 +10% |
| 期待 | 全コマンド成功率 −10% / 効果 +20% |
| 嫌悪 | 「挑発する」成功率 +25% / 効果 +10% |
| 怒り | 「説得する」成功率 +25% / 効果 +10% |
| 悲しみ | 全コマンド成功率 +5% / 効果 +5% |
| 恐れ | 「観察する」成功率 +15% / 対話を仕掛けられる確率 +10% |
| 驚き | 全コマンドの効果がランダムで ±20% |
