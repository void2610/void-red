## 現在のスコープ

**新オークションシステムのプロトタイプ実装**が目的。

- 実装対象: **オークション本体 + 洗礼 (リザルト) + ロビー**
- スコープ外: ストーリー / ノベルパート / 演出 / エンディング分岐
- 記憶データ・キャラの入札傾向は **ScriptableObject** で保持し、インスペクタで調整できるようにする
- **数値バランスは事前に確定させず、仮値で実装してから調整する**
- 旧ルール (カードバトル + 旧オークション) の実装はタグ `legacy/card-battle` に残して全消去済み。
  新ルールのプロトタイプは実装済み (対応表は [12-implementation.md](12-implementation.md))

## 改定で確定した方針 (旧記述からの変更点)

1. カードゲーム・バトルを全廃。ゲーム体験の核は「記憶オークション × 人格構築」のみ。
2. **競合中の対話コマンドはナシ**。対話は入札確定前のフェーズに限る。
3. **人格崩壊の条件は「そのオークションで 1 つも落札できなかったこと」**。リソース破産による脱落ではない。
4. **主人公が落札 0 ならゲームオーバー。その階層の最初からやり直し**。
5. セーブ / ロードあり。チャプター再生あり (ノベルスキップでオークションのみ周回可能)。
6. 所持リソース数は自分・相手とも常時可視。隠されるのは入札額のみ。
7. ロットの共鳴値は出現順と相関させずランダムに配置する。
8. エンド分岐条件は**未定** (コンプリート率には依存させない方針のみ確定)。
