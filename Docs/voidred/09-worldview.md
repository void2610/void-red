# 09. 世界観 (参考)

プロトタイプの実装には直接必要ないが、ルールの意味づけの根拠となる設定。

## VOID RED とは

ダンテの『煉獄』を元にした**試験的な新人類誕生システム**。
前提として決定論 (すべての出来事は過去の原因と自然法則によってあらかじめ決まっている) に基づく。

### 舞台

ユングの**集合的無意識**の中で新たに誕生した亜空間。
内装などは「オークション」という言葉から成るイメージ (アーキタイプ) で形作られている。
アーティファクトになるのは一部で、本来は膨大な記憶がプールされている。

### 存在意義

従来の輪廻はランダムに記憶を割り振っていたが、苦しい記憶ばかりを抱えた魂が増えた結果、
若年自殺が増加している — という因果を想定する (**シナリオ内では明言しない**)。

VOID RED はその是正のため、記憶を「選び取らせる」介入システムとして誕生した。

- 重い記憶でも自分で競り落とせば「被る運命」から「引き受けた人格」へ関係が変わる。
- 記憶の価値は関係的にしか測れないため、他者 (アーキタイプ) と比較して初めて再評価が起きる。
- この選択が救いになるかどうかは不明。**「重い記憶を選び取って勝つことは、強くなることなのか、縛られることなのか？」** を試すための実験場。

### 名前の由来

- **VOID** = 特定個人のものではなく、人類全体で共有された “所有者の本来存在しない” 記憶。あと主人公ノアのこと。
- **RED** = 人間が最初に見た赤は「血」= あらゆる時代の人間に共通する「生きて傷ついた証」。
  集合的無意識の最も根源的なイメージとしての赤。煉獄・火のイメージも兼ねる。

## 主要人物の正体

- **ノア**: VOID RED のテストプレイヤーとして用意された「空のアバター」。
  システムの成否を検証するために作られた、まだ現実に生まれていない魂。
  VOID RED での経験が、いずれ現実に生まれる一人の人間の “初期設定” になる。
  何者にも固定されていないノアだけが、他者の記憶 (罪) を偏りなく裁ける。
- **アルヴ**: 案内人でありオークショニア。第 0 階層の主。
  煉獄内の小さな罪を背負った魂から無作為に選出された凡人の一人。
  自分は選ばれた存在だと感じつつ、VOID RED の仕組みから抜け出せない蟠りを抱えている。
- **8 人の少女**: 全人類の感情に基づいて生まれた人格のアーキタイプ。
  「感情に呑まれて動けなくなった失敗例」= VOID RED が直そうとしている症状の見本。
  ノアは彼女らと競い、思想を読むことで「こうはならない自分」を選ぶ。
  ノアが敗者に植えた記憶は、その魂が次の生へ持っていく初期値になる。
  オークションの起源が少女奴隷の取引であることから、全員が少女の姿をしている。

## 枢要罪の扱い

七つの大罪の元となったエヴァグリオスの八つの枢要罪には明確な序列がある。

```
弱 ← 暴食 → 色欲 → 強欲 → 憂鬱 → 憤怒 → 怠惰 → 虚飾 → 傲慢 → 強
```

傲慢が最強なのは、それを罪だと認識できないから。

**枢要罪とは「基本感情が過剰に固着し、それに呑まれた状態」**を指す。
感情そのものは罪ではないが、ひとつの感情に自分を明け渡し、そればかりで動くようになったとき、
その感情に対応する罪へと堕ちる。

> 傲慢 = 驚き の解釈: 相手を低く見ている、今まで通りでも同じ結果だろうという傲慢さがあるからこそ、
> そうでなかったときに驚き、失望する。

## 用語

| 用語 | 意味 |
| --- | --- |
| 集合的無意識 | 個人の経験を超え、人類全体に生まれつき備わっている心の深層構造 |
| 個人的無意識 | 個人の体験で得たもの、忘れ去ったもの、抑圧した記憶 |
| 元型 (アーキタイプ) | 神話や夢に現れる「母」「英雄」「影」などの共通イメージの源泉 |
| 洗礼 | 落札した記憶を人格に統合し、次の階層へ進む儀式 |
| 楽園 | 最終階層の先。鍵を持つ者だけが到達し、自由を得る |

宗教モチーフは全体的にキリスト教ベースだが、他宗教の要素も混ぜる。
